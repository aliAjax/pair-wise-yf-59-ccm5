# 帆船赛现场控制和申诉处理

源提示词摘要：竞赛官维护组别、航线、起航时间和处罚记录，计时员提交到达数据，裁判处理抗议、重赛、弃权和成绩更正；冲突或重复处罚进入复核，操作保留时间线。

## 技术栈

React 19、TypeScript、Vite、Ant Design、Redux Toolkit、RTK Query、React Router、React Hook Form、Zod、i18next。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62024`

## 可用流程

- 竞赛控制：起航倒计时、比赛状态切换、船队和航线查看。
- 成绩管理：录入净用时和处罚秒数，标记成绩更正并发布正式成绩。
- 抗议处理：提交抗议、进入复核、支持抗议或维持原成绩，同时更新事件时间线。
- 数据使用 localStorage 持久化，刷新页面后继续保留。

## 赛后变更与名次版本（v2）

抗议裁决不再直接覆盖净用时，比赛状态、抗议处理、成绩页共用同一份赛后变更记录：

- **结束即锁定**：结束比赛时为每条船登记 `lock` 变更项并写入 `lockedElapsedSeconds`，原始到线成绩此后不可修改。
- **变更项驱动名次**：加罚、到线更正、重赛、弃权都作为新的变更项追加；净用时 = 锁定到线 + 生效加罚，重赛/弃权船不参与完赛排名。
- **并发裁决（乐观锁）**：裁决携带打开面板时的 `changeSeq` 版本号，两人同时处理同一抗议时先到的生效，后到一方看到版本冲突与按最新记录重算的当前名次，可刷新后重试。
- **失败可重试、不重复计罚**：同一抗议、同一动作、同一罚秒重试为幂等；改判（含改罚秒数）会先把原变更项标记为 `reverted` 再追加新变更项。
- **名次实时重算、发布不可变**：比赛状态或裁决项一更新，未发布名次立即重算；发布即冻结为不可变版本，首次为正式版，之后有变化另开更正版，旧版本保留查证。
- **旧数据迁移**：localStorage 中没有这些字段的 v1 数据加载时自动升级（补锁定项、迁移遗留处罚、补登已发布版本），升级后正常打开。
